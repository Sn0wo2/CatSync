# Rolling Release

This is a rolling release version, which is automatically built from the latest code. It is unstable and intended for
users who want to experience the latest features and fixes as soon as possible. Please use it with caution.

这是一个滚动更新版本，由最新的代码自动构建。它是不稳定的，适合那些希望第一时间体验到最新功能和修复的用户。请谨慎使用。

### Docker Images

```bash
docker pull ghcr.io/sn0wo2/catsync:v0.0.0-rolling
```
